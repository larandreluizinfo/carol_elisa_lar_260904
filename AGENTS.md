# Instruções para Agentes

Toda alteração neste repositório deve ser commitada e pushada imediatamente após ser feita.

## Regras

1. **Commit e Push Imediato**: Após qualquer edição de arquivo, execute:
   ```
   git add -A
   git commit -m "descrição da alteração"
   git push
   ```

2. **Mensagens de Commit**: Use mensagens claras e descritivas em português.

3. **Não deixe alterações pendentes**: Sempre que terminar de editar, faça o commit e push.
